На Воркшопе мы реализовали мультипоточную задачу, описав работу Starbucks.

Я предлагаю тебе придумать новую легенду для задачи.


Задание

Вместо работы Starbucks можешь реализовать очередь в аптеке или супермаркете, любую, придуманную тобой, историю.

Главное условие: не нужно менять используемые классы для синхронизации потоков и последовательность действий, то есть логика самого кода должна остаться такой же, а вот обертку в виде легенды можешь придумать совершенно любую.
